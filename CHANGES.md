# Changes from Arctic Fuse 3

Upstream base: `jurialmunkey/skin.arctic.fuse.3`, branch `omega`, v3.4.8 (commit c9ca43f, 2026-10-23).

## 0.2.0
- New home screen: the Lumen app dashboard (`1080i/Includes_Lumen_Dashboard.xml`), replacing the Arctic Fuse 3 hub home.
  - Top row ("Top Shelf") follows the selected tile: Umbrella → Trending this week (TMDb Helper), Live TV → On now (channels with the current programme and progress), My Library → Recently added on your NAS, Favourites → your favourites, Music → recently added albums. Every other tile shows Up next: POV Next Episodes by default (`Skin.String(Lumen.UpNext.Path)` overrides it).
  - The row switches about a second after the selection rests (`lumen_shelf` timer in `Timers.xml`), so scrolling past tiles doesn't queue a load for each one. Known edge case: a switch in the first seconds after Kodi starts can be missed while POV's first load runs; moving again fixes it.
  - Every row uses wide 16:9 cards. The card subtitle is built from season, episode and runtime, because POV's titles carry date and colour tags.
  - Background "app glow": a soft light in the selected tile's colour behind the top right, cross-fading as the selection moves.
  - 12 app tiles, 6 × 2: POV, Umbrella, YouTube, YouTube TV, Live TV, My Library, Favourites, Music, Photos, Browser, Settings, Power. My Library replaces the separate Movies and TV Shows tiles (opens `library://video/`). The selected tile grows 10% with a white ring and shadow, and shows its name.
  - YouTube, YouTube TV, Photos and Browser run `Skin.String(Lumen.Action.<Name>)` when set, else the HTPC launcher (`special://profile/scripts/launch.py`). The launcher argument names are placeholders until M2 checks them on the NUC.
  - `Skin.SetBool(Lumen.ClassicHome)` brings back the Arctic Fuse 3 home.
- Tile art and textures in `media/lumen/`, generated by `.github/art/make_tiles.py` (headless Edge for the SVG tiles, Pillow for the mask, focus ring, shadow and glow).

## 0.1.0
- Add-on ID `skin.arctic.fuse.3` → `skin.lumen`, name "Lumen", version 0.1.0. Version labels in the UI read "Lumen".
- Removed upstream's release dispatch workflow and discussion templates; added Lumen's CI, release workflow, issue templates and PR template.
