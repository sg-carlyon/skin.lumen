# Changes from Arctic Fuse 3

Upstream base: `jurialmunkey/skin.arctic.fuse.3`, branch `omega`, v3.4.8 (commit c9ca43f, 2026-10-23).

## 0.2.0
- New home screen: the Lumen app dashboard (`1080i/Includes_Lumen_Dashboard.xml`), replacing the Arctic Fuse 3 hub home.
  - Up next row: POV Next Episodes by default (`Skin.String(Lumen.UpNext.Path)` overrides it). Subtitle built from season, episode and runtime, because POV's titles carry date and colour tags.
  - 12 app tiles, 6 × 2: POV, Umbrella, YouTube, YouTube TV, Live TV, Movies, TV Shows, Music, Photos, Browser, Settings, Power. The selected tile grows 10% with a white ring and shadow, and shows its name.
  - YouTube, YouTube TV, Photos and Browser run `Skin.String(Lumen.Action.<Name>)` when set, else the HTPC launcher (`special://profile/scripts/launch.py`). The launcher argument names are placeholders until M2 checks them on the NUC.
  - `Skin.SetBool(Lumen.ClassicHome)` brings back the Arctic Fuse 3 home.
- Tile art and textures in `media/lumen/`, generated by `.github/art/make_tiles.py` (headless Edge for the SVG tiles, Pillow for the mask, focus ring and shadow).

## 0.1.0
- Add-on ID `skin.arctic.fuse.3` → `skin.lumen`, name "Lumen", version 0.1.0. Version labels in the UI read "Lumen".
- Removed upstream's release dispatch workflow and discussion templates; added Lumen's CI, release workflow, issue templates and PR template.
