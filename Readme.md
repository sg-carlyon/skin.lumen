
# Lumen [![License](https://img.shields.io/badge/license-CC--NC--SA%204.0-green)](http://creativecommons.org/licenses/by-nc-sa/4.0/)

Lumen is a Kodi 21 (Omega) skin for a living-room HTPC that runs like an appliance: a spotlight home screen, rich TV show and episode pages, and launchers for apps that run outside Kodi.

## Credits

Lumen is based on **[Arctic Fuse 3](https://github.com/jurialmunkey/skin.arctic.fuse.3)** by **jurialmunkey**. Almost all of the code and design here is his work. If you like this skin, please support the original.

Changes from Arctic Fuse 3 are listed in [CHANGES.md](CHANGES.md).

## Requirements

Kodi 21 (Omega) or later. The dependencies are the same as Arctic Fuse 3: script.skinvariables, script.texturemaker, TMDb Helper, the arctic resource image packs and resource.font.robotocjksc, all from the jurialmunkey repository.

## Development

- `main` is always installable. Work happens on `feature/*` branches and lands through pull requests.
- Upstream changes come in on `upstream/sync-<date>` branches from the `upstream` remote (`jurialmunkey/skin.arctic.fuse.3`, branch `omega`).
- Tag `vX.Y.Z` to build a release zip.
